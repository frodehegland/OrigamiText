# Origami Text — User Guide

The user guide now ships inside the app and lives at
[`Origami Text macOS/OrigamiTextUserGuide.md`](Origami%20Text%20macOS/OrigamiTextUserGuide.md).
Edit that file. Origami Text converts it to an EPUB on first launch (and
again whenever the bundled file changes), shelves it under the address
`origami-text-user-guide`, and opens it from Help ▸ Origami Text Guide.
See `RELEASE-CHECKLIST.md`: it must be updated for every App Store build.
