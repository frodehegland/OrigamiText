# Origami Text — what was built, and what to test

*27 September 2026. Everything here builds on Mac, iPad and Vision Pro, but none of it is committed yet: the last push was `b4cead3`. Most of it was checked only by building and by running the logic against test books. **Nothing listed below has been tried in the running app**, so every item is worth a look.*

Test books made along the way are in the community folder under `.check/`:

| Folder / file | What it exercises |
|---|---|
| `.check/p1/fonts.epub` | Obfuscated fonts (IDPF and Adobe) — should display in Libertinus, not a fallback |
| `.check/p1/drm.epub` | A copy-protected book — should be refused with an explanation |
| `.check/p1/plain.epub` | `&nbsp;`, Latin-1 text, broken HTML, h1/h2 levels |
| `.check/p1/epub2.epub` | EPUB 2 with an NCX contents list and a `linear="no"` page |
| `.check/p1/epub3nav.epub` | Nested contents; its unpacked copy also has a page-list and a media overlay |
| `.check/p1/rich.epub` | A plain table, ruby (furigana), an SVG cover, an audio element |
| `.check/a2/` | Copies of the AuthorKit sample (Profile 1.0), used for the Origami features |

## 1. Left column and lists

- [ ] **No "New Document / Import…" menu** anywhere when control-clicking empty space. Menus that belong to rows, pages and cards still appear.
- [ ] **No grey counts** beside rows in the left column.
- [ ] **Papers** (or **Articles**, set in Settings ▸ Layout under Journals/Proceedings) replaces Chronological and Alphabetical.
  - [ ] Its list has **Title | Date** tabs; clicking the chosen tab again reverses the order.
  - [ ] Your **name** row has the same tabs.
- [ ] **Authors** sits below Pinned.
  - [ ] Its tabs sort by **Name / Papers / Date** (date of the author's oldest paper), each reversing on a second click.
  - [ ] Right-click an author: **Pin** floats them to the top, **Set Aside** moves them under *Set Aside* at the foot, and **Bring Back** returns them.
- [ ] **Clicking a journal/proceedings** leaves only its own section in the left column (name, Authors, Concepts, Re-Analyse).
  - [ ] **Origami Text** at the top (with ‹) returns to everything, and so does **Esc**.
  - [ ] Esc a second time goes to full screen as before.
- [ ] The **Set Aside** icon is a plain down arrow, in both foot bars.

## 2. Standard EPUB 3 books (Priority 1)

- [ ] **Protected fonts:** open `fonts.epub`; the text should be in the book's font, not a fallback.
- [ ] **DRM:** import `drm.epub`; you should get "This book is copy-protected (Adobe DRM)…", not garbage.
- [ ] **Robust import:** open `plain.epub` in Full Width.
  - [ ] "Space here — and AT&T © 2026…" and "Café crème" read correctly.
  - [ ] The broken chapter reads.
  - [ ] "Chapter One" is a level-1 heading with its section below it.
- [ ] If any chapter can't be laid out, an **orange note above the reading** says so; the book isn't silently shortened.
- [ ] **Contents:** nested entries are indented, and EPUB 2 books (`epub2.epub`) have a real contents list.
- [ ] **Links between chapters** (Scrolling) move the chapter properly.
  - [ ] **‹ Back** appears top-left and returns to where you clicked.
  - [ ] **⌘[** does the same.
- [ ] **Covers:** a book's declared cover shows at the top of the native reading.
- [ ] **Fixed-layout books** (a comic or picture book): each page should fit the window, undistorted, and re-fit when the window resizes. *Not tested at all — please try one.*
- [ ] **Right-to-left books:** "Next Chapter" sits on the left.
- [ ] **Scripts:** a book that relies on JavaScript without declaring it will now not run it. Tell me if any of your books breaks.

## 3. Reading tools (Priority 2)

- [ ] **Aa panel (Scrolling):** Width (Full/Wide/Medium/Narrow), Justify, Hyphenate, and **Publisher's Styles**, which uses the book's own type.
- [ ] **Look Up / Translate** on a selection, in both Scrolling and the native styles. Check the panel appears near the words.
- [ ] **Footnotes** open in a **popup** beside their mark.
  - [ ] Settings ▸ Reading ▸ *Notes open* switches back to **In place**.
  - [ ] The [] fold style still opens in place.
- [ ] **All Chapters** in the find bar lists every match in the book; choosing one opens that chapter and finds it.
- [ ] **Progress** in the Scrolling foot bar (e.g. "34% · 12 min left").
- [ ] **Bookmarks** menu: add, jump, remove.
- [ ] **Settings ▸ Reading ▸ Reopen books where I left off** (off by default). Turned on, a book reopens at your place.
- [ ] **Go to page:** in a book that records print pages, the contents popover has a *Go to page* field.
- [ ] **Copy to Cite** on a selection in such a book shows "(Author, Year, p. 12)".
- [ ] **Read aloud (Scrolling):** the speaker button reads from the first sentence on screen, or from the selection.
  - [ ] Each sentence is highlighted as it's read.
  - [ ] Pause, resume and stop work.
  - [ ] It **carries on into the next chapter** until stopped.

## 4. Standards and exchange (Priority 3)

- [ ] **Book Information…** (empty-space menu, both modes): the book's details and accessibility statements in plain words.
- [ ] **VoiceOver:** the foot-bar icons speak their names.
- [ ] **Annotations list ▸ a book's heading ▸ right-click:**
  - [ ] **Export as EPUB Annotations…**
  - [ ] **Export as Markdown…** — open it in Obsidian; each entry has a page number where known and a link back.
  - [ ] **Export for Readwise…** — a CSV for readwise.io/import_bulk.
- [ ] **File ▸ Import Annotations…** reads an EPUB Annotations file back into the matching book.
- [ ] **Sync between Macs:** highlight on one Mac; within seconds it appears on the other, and so does your reading place. Delete a note on one; it must *stay* deleted on the other. *(iPad and Vision Pro don't share annotations this way yet.)*
- [ ] **Read-along audio:** a book with recorded narration (EPUB media overlays) plays it from the speaker button, highlighting each passage. *Untested for want of such a book.*
- [ ] **File ▸ Browse Catalogues…:** Project Gutenberg opens.
  - [ ] Follow a book to its page; **Get** imports the EPUB.
  - [ ] You can add another catalogue by address.
- [ ] **Series order:** a journal whose books record their number in a series lists them in that order.
- [ ] **Native styles** (open `rich.epub` in Full Width):
  - [ ] the table is a real grid;
  - [ ] 漢字（かんじ） keeps its reading;
  - [ ] the SVG cover shows as a picture;
  - [ ] the audio has a ▶ Play link.

## 5. Scholarly extras (Priority 4)

- [ ] **Ask** (Views ▸ Ask) now uses the model chosen in Settings ▸ AI.
  - [ ] Answers cite numbered passages, each [n] a link to its paragraph, with a **Sources** list below.
  - [ ] Try it with Ollama selected and with nothing selected (Apple's model).
- [ ] **View ▸ Paragraph Numbers:** the native styles number every paragraph in the left margin. Clicking a number copies a link to that paragraph.
- [ ] **Side by side:** right-click a book while another is open ▸ **Read Beside "…"**.
  - [ ] Both open in one window; **Sync Scrolling** keeps them at the same point.
  - [ ] **Compare Side by Side** also appears in the notice strip when a newer edition exists.

## 6. Release clean-up (code side)

- [ ] **Help menu:** *Origami Text Guide* opens the built-in guide; *Future Text Lab Website* opens the site.
- [ ] **First launch:** the guide opens by itself, once. On your Mac this happens on the next launch, the first time only.
- [ ] **The guide's text** now says Scrolling / Full Width / Papers / Authors, and describes the AI as "the model chosen in Settings".
- [ ] **New installs** show only **Ask, Glossary, Lineage** under Views; the rest are in Edit Views. Your own Views choices are unchanged.
- [ ] **Settings ▸ Library ▸ Testing** (Create Sample Community) is gone in Release builds and still there in Debug.
- [ ] **Settings ▸ AI:**
  - [ ] "Relevance to" starts empty on a new install.
  - [ ] The footer says text is sent to a server when a remote model is chosen.
- [ ] **Where Have I Read This?** footer now says ⌥⌘F.
- [ ] **No silent failures:**
  - [ ] Acquire without a community folder says why.
  - [ ] Export Library Manifest says why instead of beeping.
  - [ ] AI Analyse with no model says so.
- [ ] **Speed:** opening a book in a large library shouldn't hitch. The edition, colophon and "cited here" checks now run in the background, and the notice strip and margin marks appear a moment later.
- [ ] **Hold Up a Page** no longer reopens the camera at launch.
